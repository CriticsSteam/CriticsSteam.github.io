# Критики Steam

Статический архив проекта «Критики Steam»: история, рубрики по хэштегам, полные тексты сюрреализма, испытания критика и зал славы. Сайт — подарок подписчикам и живой вход в канал, а не только мемориал.

- Сайт: https://criticssteam.github.io
- Репозиторий (GitHub Pages, ветка `main`): https://github.com/CriticsSteam/CriticsSteam.github.io
- Telegram: https://t.me/criticssteam
- ВКонтакте: https://vk.com/criticssteam

Факты на страницах взяты из выгрузки стены ВК (vkmate.ru, посты №1–№2184, 21 июня 2020 — 6 февраля 2025) и публичной ленты Telegram (t.me/s/criticssteam, по состоянию на 10 ноября 2026). Ничего не дописано «для красоты»: рубрика ставится только по хэштегу, посты без рубричного тега — в «Без рубрики».

## Герой на главной

На главной стоят **исходники автора**, без перерисовки и без повторного вырезания:

- [`img/hero-char.png`](img/hero-char.png) — оригинальный вырез персонажа, **868×943**, PNG RGBA, скопирован байт в байт (без rembg, без обрезки, без пережатия).
- [`img/hero-mark.png`](img/hero-mark.png) — логотип Steam в круге и надпись «CRITICS STEAM», вырезанные из оригинального постера (`poster.jpg`, 1147×1008) в полном разрешении. Это не перерисованный SVG и не имитация шрифтом.
- [`img/hero-slashes.png`](img/hero-slashes.png) — синие мазки с того же постера, отдельным слоем.
- Объём: параллакс, лёгкий наклон, rim-свет CSS, туман и частицы за персонажем; при `prefers-reduced-motion` анимации отключаются.

`og:image` (`img/og.jpg`, 1200×630) кадрирован из постера так, чтобы в кадр попали и персонаж, и логотип. Favicon и apple-touch — круг логотипа Steam с того же постера.

Если понадобится снова подменить только персонажа: положите PNG поверх `img/hero-char.png` (пересборка HTML не нужна).

## Сборка с нуля

Нужны `vk_full.json`, `tg.json`, `celebs.json` и каталог `img/` (в том числе `img/vk/` и `img/tg/`). Скрипт: `/workspace/build_v4.py`. Домен задаётся переменной `SITE_URL` (по умолчанию уже `https://criticssteam.github.io`). Скрипт переписывает HTML (включая `404.html`), `data.js`, `sitemap.xml`, `robots.txt` и `rss.xml`; стили `v3.css`, скрипты `v3.js` и `games.js`, а также картинки не трогает.

В репозитории лежит `.nojekyll`, чтобы GitHub Pages не прятал файлы вроде `_manifest.json`.

## Содержимое (v4)

То же наполнение, что в v3, плюс:

- объёмный герой на главной из исходников автора (персонаж 868×943, логотип и мазки с постера, без перерисовки); параллакс, туман, частицы, rim-свет;
- кабинет испытаний (`games.html`): пять игр по архиву ВКонтакте и Telegram, рубрика #Сюрреализм в них не участвует;
- архив: фильтр тегов не прилипает при прокрутке и сворачивается кнопкой (состояние в `localStorage`);
- картинки постов пересобраны в хорошем качестве (JPEG/WebP, длинная сторона до 1600 px, для карточек — отдельные превью в `srcset`);
- служебные сообщения Telegram («Channel photo updated» и подобные) из архива убраны;
- канонические URL на боевой домен, страница 404, `.nojekyll`.

Раздел «халява» с сайта снят (историческое упоминание хэштега #халява в лонгриде и рубрика по этому хэштегу сохраняются как факт архива). Старый адрес `quiz.html` перенаправляет на испытание «Угадай знаменитость».

Новые посты из Telegram сами собой не подмешиваются: обновление архива — только по отдельному ТЗ.
